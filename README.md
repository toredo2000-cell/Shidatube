# ShidaTube 運営管理シート

Google スプレッドシート上で、ShidaTubeのShorts・通常動画・ライブ配信・切り抜き候補・投稿予定を一元管理するGoogle Apps Scriptです。

## 主な機能

- Shorts、通常動画、ライブ配信の一覧を自動更新
- 再生回数・高評価数・コメント数を記録
- 手入力したカテゴリ、評価、メモなどを更新時も保持
- Shorts・通常動画・ライブ配信の再生数TOP10をダッシュボードに表示
- 各TOP10にタイトル・投稿日・再生回数・高評価数を表示
- 切り抜き候補、投稿管理、ネタ帳の作成
- 外部スクリプトからJSONを受信するWebアプリ機能

## 導入方法

1. 対象のGoogleスプレッドシートで「拡張機能」→「Apps Script」を開きます。
2. `Code.gs` の内容をApps Scriptのエディタへ貼り付け、保存します。
3. スプレッドシートを再読み込みします。
4. メニュー「ShidaTube管理」→「運営シートを初期設定」を実行します。
5. 初回のみ権限確認画面で許可します。
6. 「ShidaTube管理」→「認証トークンを設定」を実行し、外部取得スクリプトと共通のトークンを入力します。

既存シートを更新する場合も、手順2の差し替え後に「運営シートを初期設定」を1回実行してください。旧版の「ライブ一覧」には高評価数列がないため、この処理で既存のカテゴリ・コラボ相手・メモなどを保持したまま列を追加します。その後、Windows側の更新バッチを実行すると最新の高評価数が反映されます。

## Webアプリとして公開する場合

Apps Scriptの「デプロイ」→「新しいデプロイ」からウェブアプリを選びます。アクセス権の設定は、実際の運用範囲に合わせて選択してください。公開URLは外部取得スクリプトの送信先として使用します。

POSTするJSONの例:

```json
{
  "token": "設定した認証トークン",
  "videos": [],
  "normalVideos": [],
  "streams": []
}
```

## セキュリティ

認証トークンはソースコードへ直接書かず、Apps Scriptのスクリプトプロパティに保存します。以前ソースコードに記載していたトークンは再利用せず、新しい値へ変更してください。

## ファイル

- `Code.gs`: Google Apps Script本体
- `appsscript.json`: Apps Scriptプロジェクト設定
