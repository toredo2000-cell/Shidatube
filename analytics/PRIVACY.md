# プライバシーポリシー

本アプリケーション（shidatube-analytics）は、YouTubeチャンネル「Shidatube」の
運営者自身が、自チャンネルおよび公開されている競合チャンネルの分析データを
取得・集計する目的でのみ使用する、個人利用のツールです。

## 取得する情報

- YouTube Data API および YouTube Analytics API、YouTube Reporting API を通じて、
  認可したYouTubeチャンネルの統計情報（再生回数、登録者数、視聴維持率、
  流入元、サムネイルのインプレッション数・クリック率など）を取得します。
- 月次レポート機能では、上記に加えて広告収益に関する推定値（estimatedRevenue、
  広告インプレッション数、CPMなど）を取得する場合があります。これは
  yt-analytics-monetary.readonly スコープでの追加認可と、チャンネル所有者による
  財務データ閲覧権限の付与があった場合にのみ取得され、チャンネル運営の改善検討
  （広告配置の見直し等）以外の目的には使用しません。

## 情報の利用目的

取得した情報は、チャンネル運営の改善検討のためにのみ利用し、
第三者への提供・販売は行いません。

## 情報の保管

取得したデータは、運営者が管理する環境にのみ保存されます。
